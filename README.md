# 凡人仙途 · 凡人修仙传风格弹壳特攻队（Survivors-like）

凡人修仙传风格修仙幸存者：御剑杀妖、吞噬灵气、**碎丹成婴**、**飞升灵界**、渡三千年雷劫、斩灭心魔、羽化飞升。

**完全离线运行**：全部贴图（《天道奇劫》MIT 素材 193 项 + 霞鹜文楷字体）已本地化，音效与背景音乐由 WebAudio 实时合成。

## 运行方式

直接双击打开 `index.html`（Chrome / Edge / Firefox）。或本地服务器：
```powershell
cd D:\Program\xiuxian-survivors
python -m http.server 8080
# 访问 http://localhost:8080
```

## 操作

| 按键 | 功能 |
| --- | --- |
| `WASD` / `方向键` | 御空移动 |
| `空格` | 缩地成寸（闪避位移 + 短暂无敌） |
| `1 / 2 / 3` | 升级时选择神通 |
| `Esc` | 暂停 / 继续 |

## 玩法（凡人修仙传体系）

- **十大境界**：炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升
- **原著突破机制**：
  - **金丹劫**（结丹）：引天雷淬丹，走位躲雷
  - **碎丹成婴**（元婴）：结丹大圆满金丹出窍（击碎金丹）→ **心魔**趁虚而入——**心魔是当前玩家的 1:1 复制体**：复制你全部已装备神通（含融合超武）、同等级同数值反打你，外观是暗紫色的你！击败心魔方可成婴
  - **飞升灵界**（炼虚）：化神圆满破界飞升，全屏异象
  - **三千年雷劫**：飞升灵界后每三千年一劫，**一次比一次强**（渡劫成功获道韵加持）
- **八大装备栏**：最多同时参悟 8 门神通，槽满后只能精进已有神通
- **20 门神通**：御剑术/剑气纵横/诛仙剑阵/青竹蜂云剑/剑灵分身/烈焰焚天/冰魄玄光/天雷引/千重峰/乾坤挪移/御风诀/玄金身/噬灵诀/血煞功/缩地成寸/傀儡术/噬金虫/聚灵丹/太虚剑意/天眼通
- **神通融合（超武）**：10 对配对神通都修至 5 重自动融合——
  万剑归宗、青竹诛仙阵、焚天雷劫、冰封千里、万灵朝宗、噬灵虫潮、不灭金身、瞬影流光、血噬苍穹、破妄神瞳，特效暴涨
- **妖潮与妖王**：每 30 秒一波；妖兽为高清兽形（狼妖/蜂妖/熊妖/蝠妖/蛇妖/蝎妖，蝠妖扇形弹、蛇妖毒弹、蝎妖三连射、精英狐妖追踪弹）；虎妖王 180s / 魔蛟（龙形）360s / 噬魂蛛后 540s / 心魔（人形幻影立绘）690s
- **决战结界**：妖王现身即启天罡困阵——四边金色光墙将你与妖王**困于阵内决一死战**，胜者方出！结界破碎漫天金屑
- **弹幕格挡**：诛仙剑阵（及融合版青竹诛仙阵）的环绕飞剑可**格挡普通妖弹**；**紫色必杀新星弹不可挡**，只能走位躲避
- **妖王杀招**：虎妖王环形弹幕、魔蛟扇形喷射+甩尾、蛛后蛛网+小妖潮、心魔**必杀新星**（全屏扩散紫弹）+**弹雨**+镜像分身，伤害奇高
- **飞升之约**：斩灭心魔即通关；心魔不灭，不得飞升
- **最高纪录**：localStorage 自动保存

## 素材来源

- 角色/立绘/场景/技能特效：**hetu-script/heavenly-tribulation**（《天道奇劫》，MIT License）——AI 生成仙侠风素材，经 `tools/slice-sprites.py` 切成单帧精灵、`tools/normalize-sprites.py` 归一化画布
- 妖兽（狼/蜂/熊/蝠/蛇/狐/虎/龙/蛛等 12 种）：**OpenMoji**（CC BY-SA 4.0，618×618 高清透明 PNG，jsdelivr CDN 下载）
- 字体：LXGW WenKai（霞鹜文楷，OFL 开源字体）
- 音效 / BGM：WebAudio 程序合成，零外部音频

## 开发

```
index.html          入口
css/style.css       全部界面样式（金色修仙风）
assets/images/      原始素材（下载）
assets/sprites/     切帧后的精灵（脚本生成）
assets/icons/       技能/融合图标
js/config.js        数值集中配置（境界/技能/融合/敌人）
js/assets.js        素材加载器 + 精灵帧清单
js/entities.js      玩家/敌人/Boss AI/弹幕/伤害结算
js/skills.js        20 神通 + 8 装备栏 + 满级融合
js/waves.js         波次 / Boss 时间轴 / 渡劫 / 三千年雷劫
js/render.js        贴图渲染（精灵动画/背景/特效）
js/ui.js            DOM 界面（HUD / 装备栏 / 融合横幅）
js/game.js          状态机 + 突破事件（碎丹/心魔/飞升）
tools/selfcheck.mjs 结构与素材自检：node tools/selfcheck.mjs
tools/simtest.mjs   headless 整局模拟：node tools/simtest.mjs
tools/slice-sprites.py  精灵图切帧（Python + Pillow）
```
